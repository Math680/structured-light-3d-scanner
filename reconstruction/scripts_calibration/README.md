# Calibration

Ce dossier contient les outils de calibration utiles dans la version propre.

- `ajuster_points_calibration.py` : outil graphique pour verifier/deplacer les
  points de calibration, puis enregistrer les matrices.
- Les resultats de calibration actuellement utilises sont dans
  `../calibration_validee`.
- Une copie de securite est conservee dans `../sauvegardes_calibration`.
